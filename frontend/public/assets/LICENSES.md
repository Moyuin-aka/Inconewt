# Visual asset notes

- `sprite-*.png`：改编自 Kenney 的 [RPG Urban Pack](https://kenney.nl/assets/rpg-urban-pack)，Creative Commons Zero（CC0 1.0）。
- `town-v21.webp`：为 Inconnewt v2.1 生成的原创静态场景底图。
- `town-v3.webp`：基于 v2.1 原创底图扩展生成的 v3 可探索地图，新增旧巴士站与废墟界碑。
- `resident-*.webp`：为 Inconnewt 生成的原创角色档案立绘，由原始 PNG 无损透明通道转为 WebP。
