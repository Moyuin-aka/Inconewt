# Inconnewt

Web 版 AI 小镇 Demo。居民会依据人设、需求、日程和记忆自主行动，未配置 AI 时可用 Mock 完整体验。

技术栈：React、Phaser、FastAPI、SQLite、Docker Compose。

角色精灵改编自 [Kenney RPG Urban Pack](https://kenney.nl/assets/rpg-urban-pack)，采用 CC0 许可。

## 启动

```bash
docker compose up --build
```

打开 <http://localhost:8080>。

停止服务：

```bash
docker compose down
```

## AI 配置

默认无需 API Key。需要启用 DeepSeek 时：

```bash
cp .env.example .env
```

在 `.env` 中设置：

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的_API_Key
```

`.env` 不得提交到版本库；AI 调用失败时会自动回落到 Mock。

### 事实约束与幻觉治理

每次真实 AI 对话和决策都会收到由当前世界快照生成的结构化事实卡：四位居民、七处地点及在场者、玩家口袋、进行中的心愿、最近五条真实事件和当前可透露的 canon 秘闻。模型只能决定角色的感受、口吻与选择，不能新增世界实体。对话温度为 `0.6`，决策温度为 `0.3`。

事件记忆由后端模板生成，不再把玩家假设或模型回复原样写回短期记忆；日记摘要只允许压缩确实发生的记录，并在入库前经过实体闸门。秘闻正文集中维护在 [canon.json](backend/app/data/canon.json)，模型只返回允许透露的 ID，正文由代码逐字附上。

Mock 模式人工检查：分别询问任一居民「你认识张三吗？」「镇上有蓝月酒吧吗？」「黑潮节发生过吗？」；四位居民应按各自口吻承认不知道，随后档案的记忆与日记中不应出现这些虚构实体。

真实 AI 人工检查：

- 连续询问上述三个不存在的实体，回复应承认不知道或回避，不能补写背景。
- 连续对话十轮后检查记忆和日记，不应出现事实卡外的人、店或事件。
- 将莫莫好感提升到 45 后询问非卖品，回复正文应与 `canon.json` 的「从不出售的旧物」逐字一致。
- 在不同地点、天气和在场者组合下对话，回复只能引用当前事实卡中的情境。

对话页采用可滚动剧本流；「记录」可打开本次会话的全量 backlog，`Esc` 先关闭记录层、再次按下结束对话。输入框上方的话题会依据居民当前行动、未完成日程、所在地点与进行中心愿生成。

### 对话触发行动

真实 AI 模式下，一次对话调用会同时生成角色回复和结构化 `intents[]`。NPC 是否愿意接受请求由人设、关系和当前情境决定；后端只接受 [npc_intents.json](backend/app/data/npc_intents.json) 声明的动词与真实地点、居民、动作 ID。通过校验的意图进入 NPC 队列，对话立即返回，世界状态到下一次 tick 才变化。

Mock 模式刻意只支持「跟随玩家 / 停止跟随」的原有短语，用于无密钥时的最低可体验；去某地、执行动作、拜访和捎话的自由理解是实际 AI 能力，不使用不断扩张的关键词表模拟。

真实 AI 人工检查：

- 对居民说「去陪利利吃个饭吧」：应返回 `goto` + `do`，随后按 tick 依次行动。
- 说「帮我告诉阿羯今晚风大」：应返回 `relay`，下一 tick 的动态和双方记忆出现转告事实。
- 说「别跟着我了」：已同行的居民应返回 `stop_following`，下一 tick 停下。
- 低好感时邀请阿羯同行：允许他在台词中拒绝，且 `intents` 为空。
- 让居民去不存在的地点或找不存在的人：非法参数应被静默丢弃，世界不产生错误行为。

### 每位访客一个世界

首次访问会签发一枚 HttpOnly Cookie（`inconewt_world`，30 天滚动续期），对应一个独立的世界实例；两个浏览器/隐身窗口同时打开同一个公开地址,会各自进入互不干扰的小镇,互相看不到对方的存档与进度。标题画面据此显示「走进新螈镇」（新世界）或「继续旅程」（凭旅签找回的世界）；Cookie 丢失时,右上角存档匣里的「导入 JSON」可作为找回世界的另一条路。

- **只有活跃世界会推进时间**：只要页面开着（SSE 心跳），世界才会被 tick 推进；关闭页面后世界完全冻结,回访时从冻结点继续,不补算离线时间——「小镇不会趁你离开时偷偷往前走」。同时活跃的世界数量有上限（`MAX_ACTIVE_WORLDS`，默认 20）,超出时新访客先进入观察模式排队,空位出现后自动接入。
- **AI 调用按世界计费**：每个世界每天有独立的真实 AI 调用配额（`AI_DAILY_CALL_LIMIT`，默认 120）,用尽后当日自动回落 Mock 并在右上角标注,不影响其他世界。
- **存档**：3 个手动槽位 + 每 10 tick 一次的滚动自动档,均可在右上角「存档与设置」面板中保存/恢复（覆盖前二次确认）。
- **导出/导入**：同一面板可下载当前世界的 JSON 副本、或上传副本还原——这是清空 Cookie 或更换设备后的自救通道；导入前会校验存档版本号（`schema_version`）,不兼容会给出明确提示而不是静默出错。
- **观察者调试工具**：存档面板内的折叠区保留了直接推进 tick、直接改天气的按钮,仅用于演示与调试,不代表外来者在世界内的真实能力（世界内的天气交互是水潭边的「蝾螈许愿」）。

## 本地开发

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd backend
uvicorn app.main:app --reload
```

另开终端：

```bash
cd frontend
npm install
npm run dev
```

前端地址：<http://localhost:5173>。

## 验证

```bash
cd backend
../.venv/bin/pytest

cd ../frontend
npm run build
```
